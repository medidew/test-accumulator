# Test Accumulator (TA)

Download the `ta.py` script.

```
Usage: python ta.py [csv_directory_path] -[d|w|m]
Existing flags:
  -d : groups cumulative test times by day
  -w : groups cumulative test times by commencing week
  -m : groups cumulative test times by month
```

Developed using Python 3.12.3
